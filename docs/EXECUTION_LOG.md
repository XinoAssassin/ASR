### 3.1 Core types — `backend/asr/providers/base.py` (pydantic v2; no web imports)

```python
SPEAKER_COLORS: tuple[str, ...]  # 12 fixed, distinguishable hex colours, assigned in speaker order

class Word(BaseModel):      text: str; start: float; end: float              # seconds
class Segment(BaseModel):   id: str; speaker_id: str; start: float; end: float; text: str
                            words: list[Word] = []; edited: bool = False
class Speaker(BaseModel):   id: str; name: str; color: str
class Transcript(BaseModel):
    provider: Literal["local", "cloud"]
    duration: float | None = None
    language: str | None = None
    speakers: list[Speaker] = []
    segments: list[Segment] = []
    warnings: list[str] = []
def make_speakers(speaker_ids: Iterable[str]) -> list[Speaker]   # name == id initially, colour from palette
def speaker_id(n: int) -> str                                    # 3 -> "SPEAKER_03"

class Term(BaseModel):      term: str (1..100 chars); weight: int = 3 (1..5, or 50 = boosted); note: str | None = None
ChannelsOption = Literal["auto", "downmix", "left", "right", "per_channel"]
class PreprocessOptions(BaseModel):
    channels: ChannelsOption = "auto"
    stream_index: int = 0          # audio stream among the container's audio streams
    peak_gain: bool = True         # [0d] peak-safety gain (local pipeline)
    # M6 extension point: denoise / vocal_separation / dereverb / loudness toggles (not implemented)
class LocalOptions(BaseModel):  asr_model: str | None = None; diarize_model: str | None = None; device: Literal["cpu","cuda"] | None = None
class CloudOptions(BaseModel):  model: str | None = None; keep_dialect: bool = False
class JobOptions(BaseModel):
    provider: Literal["local", "cloud"] = "cloud"
    language_hints: list[str] = ["zh", "en"]
    num_speakers: int | None = None   # None = auto; 1..20
    terms: list[Term] = []            # expanded server-side from term_set_ids + extra_terms
    context: str | None = None        # <= 2000 chars
    preprocess: PreprocessOptions = PreprocessOptions()
    local: LocalOptions = LocalOptions()
    cloud: CloudOptions = CloudOptions()

class AudioSource(BaseModel):   # exactly one of path / url
    path: Path | None = None
    url: str | None = None      # public http(s) URL; cloud provider only, the backend never fetches it
    probe: ProbeInfo | None = None

class ProgressEvent(BaseModel):
    stage: str                  # see 3.4
    progress: float             # 0..1, overall
    message: str | None = None
    external_id: str | None = None   # e.g. DashScope task_id, stored as Job.cloud_task_id
ProgressCallback = Callable[[ProgressEvent], None]   # may raise JobCancelled
class JobCancelled(Exception): ...
class ProviderError(Exception): ...                  # message is user-facing, must not contain secrets

class TranscriptionProvider(Protocol):
    name: Literal["local", "cloud"]
    def transcribe(self, source: AudioSource, options: JobOptions, progress: ProgressCallback) -> Transcript: ...
```

Providers are synchronous; the job runner calls them in a worker thread. Cancellation = the progress
callback raises `JobCancelled`, so providers call `progress()` at least every poll interval.

## 4. Decisions

| # | Decision | Reason |
|---|---|---|
| D1 | Core `Transcript` has no `id`/`job_id`/`original`; the server wraps it as `TranscriptOut` | Providers return results before ids exist; `original` is a storage concern (rule 8) |
| D2 | Per-job `cloud.endpoint` override removed; endpoint comes from settings and must match `ALLOWED_ENDPOINTS` | A user-chosen endpoint would let any API caller send the DashScope key to an arbitrary host |
| D3 | `file_url` jobs are cloud-only and the backend never fetches the URL (DashScope does); http(s) only | Removes SSRF on our side; local provider has no URL input until needed |
| D4 | Provider `local` is rejected at job creation (422) until M5 | Out of scope; better than a job that always fails |
| D5 | Default provider is `cloud` | Only implemented provider in M0–M3 |
| D6 | `X-API-Key` header only, never a query parameter. Frontend uses fetch-based SSE (`@microsoft/fetch-event-source`) and fetches audio as a Blob with the header | `EventSource`/`<audio>` cannot send headers; query keys end up in access logs |
| D7 | `ASR_API_KEY`, `ASR_UPLOAD_ROOTS`, `ASR_CORS_ORIGINS` are env-only; DashScope key / endpoint / model / provider default can be overridden in the settings table | Auth and filesystem scope must not be changeable over the API |
| D8 | Cloud audio prep: transcode to 16 kHz FLAC when size > `max_file_size_mb`, **or** when the resolved policy is `downmix` on a multi-channel file (mono FLAC); `per_channel` keeps 2-ch and sends `channel_id=[0,1]`, diarization off; `select k` sends `channel_id=[k]` | `channel_id=[0]` on correlated stereo would drop the other channel; FLAC of speech is small |
| D9 | Torch extras `cpu`/`cuda` carry only `torch` for now; `qwen-asr`/`funasr`/`modelscope` arrive with M5 | Keep M0–M3 installs and Docker builds light; tests never import torch |
| D10 | Unit tests synthesise audio with PyAV; the 20 s excerpt of `ASR_4people-test.m4a` is generated by `backend/scripts/make_fixtures.py` into `tests/fixtures/` (git-ignored) and tests that need it skip when absent | Private meeting audio stays out of git; clean checkouts still pass |
| D11 | Chunked upload is the only path the frontend uses (8 MB parts); the single multipart `POST /api/uploads` stays for curl | One code path in the UI, progress per part |
| D12 | Browser audio is a cached MP3 transcode, generated lazily on first `GET /api/audio/{id}` and served with `FileResponse` (Range) | Universal playback incl. Safari; Range seeking |
| D13 | Jobs left `running` at server start are marked `failed` ("interrupted by restart"); retry re-queues the same job | Simplest consistent state |
| D14 | `PATCH /api/transcripts` implements `edit_text` / `set_speaker` only; `split` / `merge_segments` arrive with M7 | M7 scope; contract left open for the extra ops |
